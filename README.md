# 3L0 Portal

Superfície institucional pública do ecossistema 3L0 / Symbeon Labs.

## Conteúdo público

- `index.html` — página institucional do 3L0 Vision.
- A página descreve a proposta e o fluxo de referência sem apresentar hipóteses como capacidades validadas.

## Princípios de publicação

- Distinguir claramente capacidades implementadas, experimentos e roadmap.
- Não publicar pesquisa privada, registros operacionais internos, conteúdo do vault ou alegações de desempenho não verificadas.
- Derivar as narrativas públicas da documentação canônica do produto.
- Não divulgar integrações, precisão, economia ou prontidão de produção sem evidências.

## Estado de publicação

A página está versionada na branch `main`, mas isso não significa que esteja publicada em um domínio web. A configuração de hospedagem ainda precisa ser confirmada nas configurações do repositório.

### Publicar com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **GitHub Actions** como origem.
3. Mescle a configuração de workflow aprovada e execute o workflow **Deploy GitHub Pages** em **Actions**.
4. Confirme a URL apresentada pelo GitHub Pages e teste a página em celular e desktop.

A publicação só deve ser considerada concluída depois de o workflow terminar com sucesso e a URL responder corretamente.
